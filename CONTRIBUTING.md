# Contributing

Thanks for your interest in this project!

## Reporting Issues or Suggesting Improvements

Found a bug? Have an idea for improvement? Here's how to let me know:

1. **Open a GitHub Issue** — Go to the [Issues tab](../../issues) in this repository
2. **Describe what you found** — Be as specific as possible:
   - What did you try?
   - What happened?
   - What did you expect to happen?
   - Which browser/OS are you using?
3. **That's it!** — I'll review and respond

## Types of Feedback Welcome

- 🐛 **Bugs** — Tests failing, setup instructions not working, etc.
- 💡 **Ideas** — Better ways to structure tests, additional test scenarios worth adding
- 📖 **Documentation** — Unclear instructions, typos, missing details
- 🔧 **Improvements** — Code quality, test efficiency, tooling suggestions

---

**Note:** This is a learning project, so I may not implement every suggestion, but I genuinely appreciate feedback and will consider everything thoughtfully.
